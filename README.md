# Bubble sorting algorithm
This is a classic bubble sorting algorithm. Instead of traditionally hard-coding an array inside the code, all values are being initialized throughout the terminal.
## How it works
1. Initialization of array length
2. Initialization of all array elements
3. Current array elements are being displayed in []
4. After sorting, elements of a new, sorted array are displayed in []
